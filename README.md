# Financial Crime Intelligence Dashboard

## Overview
This project presents a **Financial Crime Intelligence Dashboard** built with **Power BI** to analyze patterns, financial impact, and enforcement effectiveness of financial crimes similar to investigations handled by the Economic and Financial Crimes Commission (EFCC).

Using a **synthetic dataset**, the dashboard explores crimes such as **money laundering, cyber fraud, advance fee fraud, procurement fraud, and ponzi schemes** across different states and sectors.

The goal is to demonstrate how **data analytics and business intelligence** can support **financial crime monitoring, investigative decision-making, and risk identification**.

---

## Dashboard Structure

### 1. Executive Overview
Provides high-level KPIs and summary insights:
- Total Cases
- Total Crime Amount
- Total Fraud Amount
- Recovery Rate
- Total Arrests
- Convictions

Key visuals:
- Fraud trend over time
- Crime distribution by type
- Fraud amount by state
- Sector exposure

---

### 2. Crime Pattern Analysis
Explores **crime trends and geographic distribution**.

Key visuals:
- Monthly crime trends
- Crime type vs sector analysis
- State vs crime heatmap
- Reporting channel insights
- Crime network flow (Crime → Sector → State)

Purpose:
Identify **crime clusters and emerging patterns**.

---

### 3. Investigation & Enforcement
Evaluates **law enforcement performance**.

Metrics:
- Arrest rate
- Conviction rate
- Investigation duration
- Prosecution timelines

Key visual:
**Investigation Funnel**

Cases Reported → Arrests → Convictions → Funds Recovered

---

### 4. Financial Impact Analysis
Focuses on **economic damage caused by financial crimes**.

Key insights:
- Total financial losses
- Amount recovered
- Assets frozen
- Recovery efficiency

Visualizations:
- Loss vs recovery comparison
- Recovery rate by crime type
- Financial loss by sector
- Crime loss trend

---

### 5. Risk Intelligence
Introduces a **Crime Risk Score** to identify high-risk locations and crime categories.

The risk score combines:
- Fraud amount
- Case volume
- Arrest effectiveness

Key visuals:
- Risk heatmap
- Top high-risk states
- Risk distribution by crime type
- Decomposition tree analysis

---

## Key Features
- Interactive Power BI dashboard
- Financial crime risk scoring model
- Investigation funnel analysis
- Crime network relationship visualization
- Advanced Power BI visuals (Key Influencers, Decomposition Tree, Sankey)

---

## Tools Used
- **Power BI**
- **DAX (Data Analysis Expressions)**
- Data Modeling
- Data Visualization
- Risk Scoring Analytics

---

## Project Purpose
This project demonstrates how **data analytics can support financial crime investigations**, enabling analysts to detect patterns, monitor enforcement effectiveness, and identify high-risk areas for further investigation.
